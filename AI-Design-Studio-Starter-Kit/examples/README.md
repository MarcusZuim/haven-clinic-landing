# Exemplos fictícios

Os arquivos desta pasta mostram como preencher o kit. Todos os nomes, números e situações são fictícios e não podem ser usados como prova comercial.

- `EXAMPLE_BRIEF.md`: briefing curto.
- `EXAMPLE_CLAIM.md`: claim ainda pendente e sua versão segura.
- `EXAMPLE_ASSET_MANIFEST.md`: registro de uma imagem gerada.
- `EXAMPLE_CAMPAIGN_DIRECTION.md`: direção de campanha resumida.
