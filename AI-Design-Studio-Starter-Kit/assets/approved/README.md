# Assets aprovados de exemplo

Esta pasta acompanha uma base real da iNexxus para demonstrar como um projeto organizado guarda marca, fontes e template em locais previsíveis.

## Conteúdo

- `brand/logo-day.svg` — logo iNexxus para fundos claros.
- `brand/logo-night.svg` — logo iNexxus para fundos escuros.
- `brand/xx-official.svg` — símbolo XX oficial.
- `fonts/Archivo-Black.otf` — títulos de impacto.
- `fonts/Inter-SemiBold.otf` — texto e apoio.
- `fonts/SpaceGrotesk-Bold.ttf` — rótulos e dados.
- `templates/iNexxus-Template-Biblioteca-de-Slides.potx` — biblioteca editável 16:9.

## Regra de uso

Estes arquivos são exemplos da marca iNexxus. Em um projeto de outro cliente, substitua-os pelos arquivos oficiais recebidos e registre origem, licença e autorização em `brand/ASSET_REGISTER.md`.

Não peça à IA para redesenhar o logo. Use sempre o arquivo oficial e aplique textos, dados, CTA e avisos em camada editável.
