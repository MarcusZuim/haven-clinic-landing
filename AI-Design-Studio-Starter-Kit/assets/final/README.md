# Ativos finais aprovados

Guarde aqui apenas imagens ou elementos finais aprovados para reutilização. Peças publicáveis completas devem ir para `exports/`.

Antes de promover um ativo para esta pasta:

- [ ] origem e direitos registrados;
- [ ] artefatos revisados;
- [ ] marca e cor aprovadas;
- [ ] dimensão e perfil corretos;
- [ ] versão identificada.
