# Originais recebidos

Guarde aqui os arquivos exatamente como foram recebidos: logos, PDFs, apresentações, fotos, vídeos, planilhas e documentos.

- Não edite nem sobrescreva.
- Não renomeie sem manter uma cópia com o nome original.
- Registre origem, direitos e status em `brand/ASSET_REGISTER.md`.
- Arquivos confidenciais não devem entrar em uma entrega pública.
