# Gerações brutas de IA

Saídas originais dos geradores entram aqui antes de crop, cor, retoque ou composição.

Nome sugerido:

```text
projeto-cena-proporcao-v01.ext
```

Cada geração selecionada deve ter prompt, ferramenta, referências, data e versão registrados. Uma saída bruta nunca é considerada automaticamente pronta para publicação.
