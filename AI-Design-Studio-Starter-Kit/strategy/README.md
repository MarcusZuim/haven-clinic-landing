# Estratégia

Esta pasta conecta pesquisa e produção. Antes de criar peças, documente:

- público prioritário e ação desejada;
- problema e promessa defensável;
- posicionamento;
- conceito central;
- dispositivo visual;
- pilares e matriz de conteúdo;
- jornada ou funil;
- critérios de sucesso.

Use `templates/CAMPAIGN_CONCEPT_TEMPLATE.md` como ponto de partida e salve a direção aprovada como `CONCEPT.md`.
