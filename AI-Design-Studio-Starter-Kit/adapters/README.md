# Adaptadores para IAs e IDEs

O conhecimento do kit é neutro. Os arquivos na raiz apenas apontam diferentes ferramentas para a mesma fonte:

- `AGENTS.md`: contrato universal.
- `CLAUDE.md`: importação para Claude.
- `GEMINI.md`: importação para Gemini.
- `.cursor/rules/00-project.mdc`: regra permanente do Cursor.
- `.github/copilot-instructions.md`: instruções do Copilot.
- `prompts/START_HERE.md`: alternativa para qualquer chat.

Não replique o conteúdo em vários lugares. Atualize primeiro `AGENTS.md` e mantenha os adaptadores curtos.
