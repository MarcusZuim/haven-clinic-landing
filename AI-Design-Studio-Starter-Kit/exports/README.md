# Exportações

Somente arquivos aprovados ou claramente marcados como prévia entram aqui.

Subpastas recomendadas:

- `web/`
- `pdf/`
- `pptx/`
- `feed/`
- `stories/`
- `video/`

Nome recomendado:

```text
cliente-entregavel-formato-v01-AAAA-MM-DD.ext
```

Não inclua fontes sem licença, originais confidenciais, caches ou credenciais.
