# QA responsivo e acessibilidade

## Viewports mínimos

- [ ] Mobile: 390 px
- [ ] Tablet: 768 px
- [ ] Desktop: 1440 px
- [ ] Orientação ou largura adicional exigida pelo briefing

## Layout

- [ ] Não existe rolagem horizontal inesperada
- [ ] Conteúdo não fica escondido sob header fixo
- [ ] Seções mantêm hierarquia em todas as larguras
- [ ] Imagens usam crop adequado ao formato
- [ ] Vídeos e embeds cabem no viewport
- [ ] Elementos flutuantes não cobrem conteúdo
- [ ] Tela de carregamento ou idioma possui fallback e não trava

## Texto e interação

- [ ] Corpo possui pelo menos 16 px no mobile
- [ ] Linha tem comprimento confortável
- [ ] Alvos de toque têm pelo menos 44×44 px
- [ ] Links e botões possuem estado de foco visível
- [ ] Ordem de Tab acompanha a ordem visual
- [ ] Formulários possuem label e feedback claro
- [ ] Ícones isolados possuem nome acessível

## Imagens e movimento

- [ ] Imagens significativas possuem alt text
- [ ] Imagens decorativas são ignoradas por leitor de tela
- [ ] Espaço é reservado para mídia assíncrona
- [ ] Arquivos são otimizados e proporcionais ao dispositivo
- [ ] `prefers-reduced-motion` é respeitado
- [ ] Informação essencial não depende apenas de animação ou cor

## Funcionamento

- [ ] Links internos e externos testados
- [ ] Navegação funciona por teclado
- [ ] Não há erro de console relevante
- [ ] Não há mídia ausente ou requisição quebrada
- [ ] Página continua compreensível sem JavaScript quando previsto
- [ ] Teste realizado a partir da pasta/build final
