# QA de entrega e handoff

## Escopo e inventário

- [ ] Cada entregável aprovado está presente
- [ ] Quantidade e formatos correspondem ao briefing
- [ ] Arquivos possuem versão e nome compreensível
- [ ] Prévias estão claramente separadas dos finais
- [ ] Pendências estão documentadas

## Abertura

- [ ] HTML abre a partir da pasta final ou servidor simples
- [ ] PDF abre e possui todas as páginas
- [ ] PPTX abre e mantém a editabilidade prometida
- [ ] Vídeos reproduzem até o fim
- [ ] Imagens possuem dimensão e perfil adequados
- [ ] Fontes ou fallbacks necessários estão documentados
- [ ] Não há dependência silenciosa da pasta de produção

## Versões

- [ ] Alta qualidade foi preservada
- [ ] Versão leve existe quando solicitada
- [ ] Editáveis estão incluídos quando fazem parte do escopo
- [ ] Originais recebidos não foram sobrescritos
- [ ] Versões antigas relevantes estão em `archive/`

## Instruções

- [ ] README indica como abrir e usar
- [ ] Dependências são explicadas em linguagem simples
- [ ] Responsável sabe qual arquivo é a versão final
- [ ] `MEMORY.md` contém o estado final e próximo passo
- [ ] Inventário foi enviado junto da entrega

## Teste externo

- [ ] Arquivos foram abertos a partir da pasta de entrega
- [ ] Quando possível, teste foi feito em outro navegador ou aplicativo
- [ ] Hash foi gerado quando integridade for necessária
