# Website responsivo

## Quando usar

Para site institucional, landing page, relatório interativo ou página de campanha.

## Entradas

Objetivo, público, sitemap, copy, brand spec, assets e ação principal.

## Procedimento

1. Defina jornada e arquitetura antes da estética.
2. Crie sistema de cores, tipo, espaçamento e componentes.
3. Use HTML semântico e progressive enhancement.
4. Garanta fonte de corpo de pelo menos 16 px no mobile.
5. Use alvos de toque de pelo menos 44×44 px.
6. Adicione alt text, foco visível e redução de movimento.
7. Otimize imagens e reserve espaço para evitar saltos.
8. Teste 390, 768 e 1440 px, teclado, console e links.

## Saída

Fonte editável, build portátil quando solicitado e capturas de QA.

## Critério de conclusão

Não há rolagem horizontal, mídia ausente, erro de console ou conteúdo escondido; a jornada funciona nos três breakpoints.

## Erros a evitar

Tela de idioma travada; animação cobrindo rosto ou texto; contraste insuficiente; versão mobile tratada como desktop reduzido.
