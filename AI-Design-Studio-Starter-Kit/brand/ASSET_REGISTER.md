## Checklist antes de usar um ativo

- [ ] É a versão oficial mais recente
- [ ] A origem está registrada
- [ ] O uso está autorizado para o canal
- [ ] A qualidade é suficiente para o formato
- [ ] Não contém dado pessoal desnecessário
- [ ] Não possui link assinado ou metadado sensível
- [ ] O arquivo original permanece em `assets/source/`
