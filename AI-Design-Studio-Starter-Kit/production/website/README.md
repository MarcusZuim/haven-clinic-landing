# Website

Fontes editáveis do site ou landing page. A entrega portátil ou publicada pertence a `exports/web/`.

## Radial Reveal Button (Originkit)

Componente instalado em `src/components/originkit/ui/radial-reveal-button.tsx`. A landing ainda não existe; esta pasta só segura a animação para reutilizar no site.

Prévia local:

```powershell
Set-Location -LiteralPath '.\production\website'
npm install
npm run dev
```

Abra `http://localhost:5173` e passe o mouse no botão.
