# Pesquisa

Guarde aqui auditoria de mercado, concorrentes, público, referências e evidências. Toda conclusão factual deve apontar para `SOURCES.md`.

Arquivos recomendados:

- `SOURCES.md`: registro mestre de fontes.
- `MARKET.md`: mercado e contexto.
- `COMPETITORS.md`: concorrentes e padrões da categoria.
- `AUDIENCES.md`: necessidades, objeções e linguagem dos públicos.

Separe fatos de inferências. Registre data de acesso porque páginas e condições podem mudar.
